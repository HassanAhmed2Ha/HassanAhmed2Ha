### 🧬 BioPhys Refinement Lab

**Physics-Based Protein Structure Refinement**

AI-predicted protein structures are full of steric clashes and unphysical energies — they can't be used directly for drug docking. This platform takes those broken structures, repairs their topology with PDBFixer, and runs **OpenMM energy minimization** (AMBER14 force field) to produce thermodynamically stable conformations. The backend runs on **Modal serverless GPU infrastructure**. The frontend gives researchers a clean interface to upload, refine, and download.

<details>
<summary>🔬 Architecture Deep-Dive (click to expand)</summary>
<br/>
<b>Serverless GPU Backend</b> (<code>modal_app.py</code>):
<ul>
<li>FastAPI gateway on Modal with two-layer CORS middleware</li>
<li>Async job architecture: <code>POST /</code> returns a <code>job_id</code> instantly → GPU worker processes in background → client polls <code>GET /status/{job_id}</code></li>
<li>GPU worker config: <code>gpu="A10G"</code>, <code>memory=4096</code> (line 75)</li>
<li>Calls ESMFold API (<code>api.esmatlas.com</code>) for sequence-to-structure prediction (line 103)</li>
</ul>
<b>Two-Pass Topology Repair</b> (<code>pdb_prep.py</code>):
<ul>
<li>Pass 1: Strip non-standard residues (UNK) and heterogens via PDBFixer + OpenMM Modeller</li>
<li>Pass 2: Reload cleaned PDB, detect chain breaks, add terminal caps and hydrogens at pH 7.4</li>
<li>Critical lesson: deleting residues AFTER <code>addMissingAtoms()</code> creates dangling bonds — order is everything</li>
</ul>
<b>Energy Minimization</b> (<code>minimization.py</code>):
<ul>
<li>AMBER14 + GBn2 implicit solvent</li>
<li>Harmonic positional restraints on C-alpha backbone atoms</li>
<li>Platform auto-detection: CUDA → OpenCL → CPU fallback</li>
<li>Capped at 100 iterations to prevent HTTP gateway timeouts</li>
</ul>
<b>Quality Metrics</b> (<code>metrics.py</code>):
<ul>
<li>pLDDT confidence extraction from PDB B-factor column</li>
<li>C-alpha RMSD computation via MDTraj</li>
</ul>
<b>Frontend:</b> React 18 + Vite + Tailwind CSS + Framer Motion + Axios
</details>

### 🧠 NeuroScan AI

**Explainable Breast Cancer Diagnosis**

Most ML models are black boxes. Clinicians won't trust a prediction they can't explain. NeuroScan accepts 5 clinical tumor measurements, returns a **malignant/benign prediction** with a confidence score, and generates **per-feature SHAP explanations** showing exactly which measurements drove the decision. This isn't a notebook — it's a **fully deployed production system**.

<details>
<summary>🔬 Architecture Deep-Dive (click to expand)</summary>
<br/>
<b>Neural Network</b> (<code>API.py</code>):
<ul>
<li>Keras Sequential: <code>Input(5) → Dense(32, relu) → Dense(16, relu) → Dense(8, relu) → Dense(1, sigmoid)</code></li>
<li>GPU explicitly disabled: <code>CUDA_VISIBLE_DEVICES = "-1"</code></li>
<li>StandardScaler + model weights loaded at startup via <code>joblib</code></li>
</ul>
<b>SHAP Explainability</b> (lines 74-87):
<ul>
<li><code>KernelExplainer</code> with lazy initialization — built once on first request</li>
<li>Background dataset: 20 training samples for the baseline</li>
<li><code>nsamples=40</code> for real-time response speed</li>
</ul>
<b>⚠️ The Scaler Bug:</b> After deployment, the model predicted "Malignant" for every input. Root cause: the <code>StandardScaler</code> fitted during training was never saved. The API received raw feature values — a completely different distribution. Fixed by persisting with <code>joblib.dump()</code> and calling <code>scaler.transform()</code> before every prediction.
<br/><br/>
<b>Deployment:</b>
<ul>
<li>Backend: FastAPI + Uvicorn in Docker (<code>python:3.10-slim</code>) on HuggingFace Spaces</li>
<li>Frontend: React 18 + Vite + Tailwind CSS + Framer Motion on Vercel</li>
<li>Full deps: <code>fastapi · uvicorn · tensorflow-cpu · numpy · pydantic · joblib · scikit-learn · shap</code></li>
</ul>
</details>
