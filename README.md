## 🧬 The Thesis

> *"Biology generates the hypotheses. Computation validates them. Engineering deploys them at scale."*

I am an undergraduate researcher at the **Faculty of Agriculture** with a singular focus: **applying deep learning, molecular dynamics, and data engineering to accelerate drug discovery and decode biological complexity.** My work exists at the precise intersection where agricultural genomics meets clinical bioinformatics — a convergence that most researchers overlook but that holds the key to understanding plant-derived therapeutics, antimicrobial resistance in food chains, and environmentally-mediated public health crises.

I don't just train models. I build **production-grade, GPU-accelerated pipelines** that transform raw biological data into actionable scientific insight — from protein structure refinement on NVIDIA A10G GPUs to explainable tumor classification systems deployed on the edge.

**Accepted into the [Global Creative Informatics (GCI) World 2026](https://gci.t.u-tokyo.ac.jp/)** program at the **Matsuo Laboratory, The University of Tokyo** — one of the world's foremost deep learning research labs — as recognition of my capabilities in neural network architectures, generative AI, and computational systems design.

### 🧬 [BioPhys Refinement Lab](https://github.com/HassanAhmed2Ha/biophys-refinement-lab)

**Solving the "AI Hallucination Problem" in Protein Structure Prediction**

<br/>

| Dimension | Detail |
|:--|:--|
| **Problem** | AI-predicted protein structures (AlphaFold, ESMFold) contain steric clashes, unphysical energies (>50,000 kJ/mol), and missing hydrogen networks — rendering them unusable for drug docking |
| **Solution** | GPU-accelerated molecular dynamics refinement using AMBER14 force field with restrained Calpha minimization on NVIDIA A10G |
| **Innovation** | Two-pass PDBFixer pipeline for robustly handling experimental PDB defects (UNK residues, missing terminal caps) |
| **Result** | 98% repair rate, >70,000 kJ/mol energy reduction, RMSD < 0.5 A backbone preservation |
| **Architecture** | Async polling system (React + FastAPI + Modal GPU) solving HTTP gateway timeout for 10-min GPU computations |

`Python` `OpenMM` `CUDA` `FastAPI` `React` `Modal` `PDBFixer` `MDTraj`

### 🧠 [NeuroScan AI](https://github.com/HassanAhmed2Ha/NeuroScan-AI)

**Explainable Deep Learning for Clinical Tumor Diagnosis**

<br/>

| Dimension | Detail |
|:--|:--|
| **Problem** | ML models for medical diagnosis operate as black boxes — clinicians cannot trust predictions without understanding the reasoning |
| **Solution** | End-to-end tumor classification system with SHAP-based feature attribution for every prediction |
| **Innovation** | Lazy SHAP initialization + StandardScaler consistency pipeline solving the critical "always-predicts-malignant" deployment bug |
| **Result** | Real-time malignant/benign classification with per-feature clinical interpretability |
| **Architecture** | TensorFlow model + FastAPI backend (HuggingFace Spaces) + React frontend (Vercel) |

`Python` `TensorFlow` `SHAP` `FastAPI` `React` `Docker` `HuggingFace`
